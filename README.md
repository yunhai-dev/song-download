# 音乐下载

Rust / GPUI 桌面工具。用 QQ 音乐或网易云音乐账号扫码，浏览自建及收藏歌单，把平台授权的整首音频、封面和歌词下载到本地。

## 运行

需要近期稳定版 Rust 和 Node.js 22 或更新版本。已在 Apple Silicon macOS 上验证构建和窗口启动；macOS 需要安装 Xcode 或 Command Line Tools。

```sh
npm ci --ignore-scripts
cargo run --locked
```

Rust 应用会启动本地适配器，无需手动开服务。适配器仅监听随机回环端口；登录凭据不保存到磁盘，重新打开应用后需再扫码。

## 下载

1. 选择平台并生成登录二维码。QQ 音乐使用 QQ 音乐 App 扫码，网易云音乐使用网易云音乐 App 扫码。按手机提示确认。
2. 在左侧选择歌单。长歌单可以点「加载更多」。
3. 选择下载目录，再点击歌曲右侧的「下载」。可以连续添加多首；只有当前歌曲显示「下载中」，其余任务按顺序排队。

逐字歌词保留平台的时间戳：QQ 音乐保存为 `.qrc`，网易云音乐保存为 `.yrc`。只有逐行歌词时保存 `.lrc`；没有歌词、封面或对应接口失败时，已保存的音频仍然保留。同名文件不会被覆盖。

**只下载账号有权获取的整首歌曲。** 不尝试解锁受限歌曲，不把试听片段保存为整首。会员、地区和版权限制由平台决定，请在授权范围内保存文件。

## 下载管理

从左侧打开「下载管理」，查看每首歌的排队、下载中、完成或失败状态。可取消排队任务、重试失败任务，或定位已保存的音频文件。封面和歌词的结果单独显示。

完成记录会保留，关掉应用再打开仍可标记「已下载」。仅从本版本开始记录；升级前的文件不会按歌名猜测匹配。排队和失败任务不跨重启保留。

## 排查

- **适配器未就绪**：确认 `node` 在 `PATH` 中，并在项目目录执行 `npm ci --ignore-scripts`。可运行 `node bridge/main.cjs --check` 检查依赖和本地二维码生成。
- **二维码过期或账号失效**：重新生成二维码；已登录时先点「退出本地登录」。两家平台的登录状态彼此独立。
- **平台接口出错**：适配方式参考 [Folia Major](https://github.com/chthollyphile/folia-major)，复用其 QQ 和网易云 API npm 依赖。平台协议可能变化；如需定位，运行 `cargo test --locked` 检查本地解析和写入，再用账号做端到端联调。
